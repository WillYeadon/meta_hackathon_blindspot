DOMAIN EXPERTISE AND CODING AGENTS

Designed by a physicist, implemented with coding agents

I’m Will Yeadon, an assistant professor of physics interested in reliable AI for scientific reasoning. I designed the experiments, requirements for exact ground truth and interpretation; coding agents generated and iterated the implementation during the hackathon.

Current scope

The current build runs the included physics test suites, lets users inspect saved verifier behaviour, compare tested configurations and reproduce the analysis. Adding a new scientific domain requires implementing a new test suite and an independent correctness oracle. Automatic verifier routing is a future extension.

How to add another scientific stress test
  1. Choose a claim with an independent oracle. Know whether it is correct without trusting the AI reviewer.
  2. Choose a truth-preserving transformation. Change the representation while preserving the target physical fact.
  3. Create matched correct and incorrect claims. Hold irrelevant details fixed wherever possible.
  4. Run the verifier across equivalent cases. Measure wrong PASSes, false alarms, missing answers and cost.
  5. Choose the verifier configuration. Assess whether the cheap checker is adequate, benefits from trusted information or needs escalation.

Implemented spectral test: exact basis transformation → spectrum and energy splitting stay fixed → exact linear algebra supplies the oracle.

Hypothetical relativity extension: describe the same spacetime in different coordinates, choose a coordinate-invariant physical quantity at corresponding physical points, and check it with an independent symbolic or numerical relativity calculation. Metric components themselves need not stay the same.

This relativity example is an extension pattern. It is not implemented or experimentally tested in this release.

THE EVALUATION HARNESS

Known physics. Tested reviewer.

  1. Start with an exact oracle. Generate a spectrum and verify all matrix identities with rational arithmetic.
  2. Hold truth fixed. Present the same right or wrong gap claim through different exact bases.
  3. Measure verdicts. Record missed errors, rejected correct controls, unavailable responses and costs. Technical pilots are separate.
  4. Test a remedy. Supply trusted checkpoints or compare a stronger verifier on the same cases.

The recorded prompts used coupled modes. A four-level Hamiltonian is the physical interpretation of that exact spectral problem. This is calibration of the AI reviewer; the exact eigensolver already supplies the answer.

The twelve held-out spectra belong to an adaptively discovered family. Higher-model settings have one attempt per fixed cell. These results do not certify general scientific-review competence or reveal internal model mechanisms.
