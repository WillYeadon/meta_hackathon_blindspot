# The completed fixed study

The current reproduction entry point is [REPRODUCIBILITY.md](../REPRODUCIBILITY.md).
Scientific conclusions and limitations are in [FINAL_FINDINGS.md](../FINAL_FINDINGS.md).
Data collection is closed; these records are not a request for new experiments.

The study fixes twelve held-out general-rational spectra, nine candidate claims
and the baseline/Trusted Checkpoints conditions. Spark-low uses twenty attempts
per cell, reusing the original baseline and full-certificate measurements. Its
checkpoint intervention adds only the exact outer eigenvalues.

The original max-effort settings remained technical pilots. An explicit
high-effort continuation and then a larger completion-token allowance completed
the same panel. Both added configurations used 32,768 total completion tokens
and one attempt per cell. The common repeat count was selected on cost before
main collection; no failed main cell was selectively repurchased.

The public source includes `data/final-panel-plan.json` and
`data/final-panel-continuation.json`. `data/final-panel-public.json` preserves the
measured results while omitting personal credit-balance and authorisation data.
The raw SQLite snapshots and full operational extension record remain in the
creator’s local working copy. Earlier collection instructions are archived there.

“Trusted Checkpoints” is the presentation label for the unchanged archival key
`outer_anchors`. The original mathematical claims and coupled-mode prompts are
preserved. Public tests reconstruct their fixtures from public banks and plans;
they do not need private review ZIPs or a live key.
